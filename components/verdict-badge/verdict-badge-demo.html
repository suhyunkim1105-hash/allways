1. Default — 기본

Icon + short label + color. No border. This is what always renders on the page.

2. Hover / focus — 커서 댔을 때

Same badge, same fill — a 1px border in the same color appears on hover/focus. (Hover the badges below.)

3. Hover detail tooltip — 상세정보

Hover or focus the badge to see the full state name + explanation. Not surveyed has no tooltip — there's nothing to explain about data that doesn't exist yet.

4. Three sizes

5. In context

size="detail" — top of a detail page (hover the badge)
size="card" — inside a summary card (hover the badge)
size="list" — dense list/table rows (no fabricated figures; unknown rows fall back to Not surveyed, rule #4)
